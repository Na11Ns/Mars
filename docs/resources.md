# 🧰 Resources

## Discovery (Prowl)
- [Dexscreener](https://dexscreener.com) — new pairs, volume, charts across chains
- [GMGN](https://gmgn.ai) — new launches, smart-money flows
- [CoinGecko](https://www.coingecko.com) — listings, categories, market overview
- [Birdeye](https://birdeye.so) — Solana token analytics

## On-chain checks (Stalk)
- [Solscan](https://solscan.io) — Solana explorer: holders, authorities, transfers
- [Basescan](https://basescan.org) — Base explorer
- [Etherscan](https://etherscan.io) — Ethereum explorer
- [RugCheck](https://rugcheck.xyz) — Solana token risk overview

## Journaling (Groom)
- `diary/` — one entry per trade
- `logs/trades.csv` — the ledger
- `mars stats` — terminal report

## Safety
- Never paste a seed phrase anywhere. Not in a DM, not in a site, not in this repo.
- Bookmark the tools above; scammers clone them.
- The only official Mars wallet is the one at the top of the README.
