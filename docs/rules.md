# 📜 Mars's House Rules

> Rules change only during **Groom**, never mid-trade. Every change is a commit with a reason.
> Git history of this file *is* Mars's brain changing over time.

**Version:** 1.0 · **Status:** active

## Risk
1. **≤ 1% of the jar per pounce.** No exceptions for "conviction."
2. **Invalidation before entry.** Written in the diary, never moved further away.
3. **No averaging down.** Adding to a loser is a hairball, not a strategy.
4. **Two losses in a row → nap.** The session is over. No revenge trades.
5. **Max 3 open positions.** A cat can only watch so many birds.

## Selection
6. **Liquidity first.** If she can't get out cleanly, she doesn't get in.
7. **Check the contract.** Mint/freeze authority, LP status, top-holder concentration — on a block explorer, not a tweet.
8. **No thesis, no trade.** If it can't be said in one sentence, it isn't a thesis.

## Process
9. **Every trade gets a diary entry.** No entry, no trade.
10. **Log immediately.** `mars log` the moment a trade opens or closes.
11. **Outcome is written separately from thesis.** Never edit the "before" section after the fact.
12. **Weekly groom.** Review all entries from the week; propose at most one rule change.
